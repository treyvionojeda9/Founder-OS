# Founder OS one-page product contract (Chapter 1 template)

Record the primary user, device, work to be done, data ownership, offline needs, and prohibited actions before opening an AI coding tool.

- User: one owner with possible future team members.
- Interface: pen-first when a stylus exists (such as TCL Note A1 NXTPAPER); accessible typing, mouse, touch, and optional speech elsewhere.
- Source of truth: human-authored pages, stored as original strokes or text with revision history in Human Vault.
- Machine space: derivative transcripts, links, lesson plans, agent reports, and suggestions stored in Machine Vault and labeled as generated.
- Offline promise: capture, view cached content, and search local material without the network.
- Private cloud: owner-controlled NAS or server with authenticated synchronization; no mandatory paid sync provider.
- Approval boundary: no autonomous spending, publishing, outbound contact, deletion, or production deployment without explicit human permission.
